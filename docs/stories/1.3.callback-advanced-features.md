### Data Models
[Source: Existing types and callback extensions]

**Extended CallbackConn Structure:**
```go
type CallbackConn struct {
    // ... existing fields from Stories 1.1 and 1.2 ...
    
    // Heart-beat and health monitoring
    readTimeout time.Duration
    writeTimeout time.Duration
    healthStatus ConnectionHealth
    heartBeatCallback HeartBeatCallback
    healthStatusCallback HealthStatusCallback
    
    // Transaction support
    transactions map[string]*CallbackTransaction

    stats ConnectionStats
}
```

**New Callback Function Types:**
```go
type HeartBeatCallback func(conn *CallbackConn, event HeartBeatEvent, err error)
type TransactionCallback func(conn *CallbackConn, tx *CallbackTransaction, event TransactionEvent, err error)
type ErrorRecoveryCallback func(conn *CallbackConn, err error, recoveryAction RecoveryAction) RecoveryDecision
type HealthStatusCallback func(conn *CallbackConn, oldStatus, newStatus ConnectionHealth)
type ShutdownCallback func(conn *CallbackConn, err error)
```

**CallbackTransaction Structure:**
```go
type CallbackTransaction struct {
    id string
    conn *CallbackConn
    state TransactionState
    callback TransactionCallback
}
```

### API Specifications
[Source: Callback pattern design and existing transaction/heartbeat operations]

**Heart-Beat and Health Methods:**
- `SetHeartBeatCallback(callback HeartBeatCallback)`
- `SetHealthStatusCallback(callback HealthStatusCallback)`
- `GetHealthStatus() ConnectionHealth`
- `GetConnectionStats() ConnectionStats`

**Transaction Methods:**
- `Begin(callback TransactionCallback) (*CallbackTransaction, error)`
- `(*CallbackTransaction).Commit(callback TransactionCallback) error`
- `(*CallbackTransaction).Abort(callback TransactionCallback) error`
- `(*CallbackTransaction).Send(destination, contentType string, body []byte, callback SendCallback, opts ...SendOption) error`

**Error Handling and Recovery:**
- `SetErrorRecoveryCallback(callback ErrorRecoveryCallback)`
- `SetShutdownCallback(callback ShutdownCallback)`
- `Close(callback ShutdownCallback) error`

**Enhanced Messaging Methods:**
- `SendTx(tx *CallbackTransaction, destination, contentType string, body []byte, callback SendCallback, opts ...SendOption) error`
- `AckTx(tx *CallbackTransaction, message *CallbackMessage, callback AckCallback) error`
- `NackTx(tx *CallbackTransaction, message *CallbackMessage, callback AckCallback) error`
