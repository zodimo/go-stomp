### Data Models
[Source: Existing types and new callback extensions]

**Extended CallbackConn Structure:**
```go
type CallbackConn struct {
    // ... existing fields from Story 1.1 ...
    
    // Message handling
    subscriptions map[string]*CallbackSubscription
    messageHandlers map[string]MessageHandler
    
    // Callback handlers for messaging operations
    sendCallback SendCallback
    subscriptionCallback SubscriptionCallback
    ackCallback AckCallback
}
```

**New Callback Function Types:**
```go
type SendCallback func(conn *CallbackConn, destination string, err error)
type MessageHandler func(conn *CallbackConn, message *CallbackMessage)
type SubscriptionCallback func(conn *CallbackConn, subscription *CallbackSubscription, event SubscriptionEvent, err error)
type AckCallback func(conn *CallbackConn, messageId string, err error)
```

**CallbackSubscription Structure:**
```go
type CallbackSubscription struct {
    id string
    destination string
    ackMode AckMode
    handler MessageHandler
    conn *CallbackConn
    active bool
}
```

**CallbackMessage Structure:**
```go
type CallbackMessage struct {
    Header *frame.Header
    Body []byte
    Subscription *CallbackSubscription
    Conn *CallbackConn
    ackId string // for acknowledgment operations
}
```

**Subscription Events:**
```go
type SubscriptionEvent int
const (
    SubscriptionCreated SubscriptionEvent = iota
    SubscriptionActive
    SubscriptionUnsubscribed
    SubscriptionError
)
```

### API Specifications
[Source: Callback pattern design and existing STOMP operations]

**Message Sending Methods:**
- `Send(destination, contentType string, body []byte, callback SendCallback, opts ...SendOption) error`
- `SendWithReceipt(destination, contentType string, body []byte, callback SendCallback, timeout time.Duration, opts ...SendOption) error`

**Subscription Management Methods:**
- `Subscribe(destination string, ackMode AckMode, handler MessageHandler, callback SubscriptionCallback, opts ...SubscribeOption) (*CallbackSubscription, error)`
- `Unsubscribe(subscription *CallbackSubscription, callback SubscriptionCallback) error`

**Message Acknowledgment Methods:**
- `Ack(message *CallbackMessage, callback AckCallback) error`
- `Nack(message *CallbackMessage, callback AckCallback) error`

**Callback Registration Methods:**
- `SetSendCallback(callback SendCallback)`
- `SetSubscriptionCallback(callback SubscriptionCallback)`
- `SetAckCallback(callback AckCallback)`
