# Story 2.1: Implement Background Frame Reader

## Status
done

## Story
**As a** Go developer using the callback-style STOMP client,
**I want** a persistent background frame reader that continuously reads frames from the connection,
**so that** I can avoid race conditions between multiple operations and ensure reliable frame routing without missed RECEIPT frames.

## Acceptance Criteria
1. Create a persistent goroutine that continuously reads frames from the connection
2. Implement proper error handling and connection cleanup
3. Ensure the reader starts when connection is established and stops when disconnected
4. Add comprehensive logging for debugging

## Dev Notes

### Current Architecture Issues
[Source: Epic analysis and codebase investigation]

**Race Condition Problem:**
- `performConnect()` creates reader at line 348: `reader := frame.NewUnwrapCbioReader(c.conn)`
- `performDisconnect()` creates reader at line 495: `reader := frame.NewUnwrapCbioReader(c.conn)`
- `startMessageProcessing()` creates reader at line 573: `reader := frame.NewUnwrapCbioReader(c.conn)`
- Multiple readers compete for the same connection, causing race conditions and missed frames

**Current Frame Reading Pattern:**
- Each operation creates temporary readers for specific frame types (CONNECTED, RECEIPT, MESSAGE)
- Operations use context with timeout for frame reading
- No centralized frame routing - each reader only looks for specific frame types
- RECEIPT frames can be consumed by wrong operation, causing timeouts

### Previous Story Context
From Story 1.4: The CallbackConn API was migrated to use cbio interfaces consistently. The frame operations now use `frame.NewUnwrapCbioReader(c.conn)` and `frame.NewUnwrapCbioWriter(c.conn)` for frame I/O operations. The connection maintains proper cbio interface usage throughout.

### API Specifications
[Source: Epic technical architecture and existing patterns]

```go

```

**Frame Reading Loop Pattern:**
```go
func (c *CallbackConn) frameReaderLoop() {
    reader := frame.NewUnwrapCbioReader(c.conn)
    defer close(c.readerDone)
    
    for c.GetState() == Connected {
        frame, err := reader.ReadSync()
        if err != nil {
            c.errorChannel <- err
            return
        }
        c.frameChannel <- frame
    }
}
```
